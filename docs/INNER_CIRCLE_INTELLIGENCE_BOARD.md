# Inner Circle — intelligence board

The member landing view is an editorial intelligence board. It retains the monthly feature, agenda, opportunities and working library.

Four selectable desks: strategic developments (four sourced signals from this edition), economic diplomacy (market-access case and institutional decision map), advocacy (policy windows and declared-interest mapping), and curated official resources. Editorial cutoff: 31 October 2026. This is an editorial snapshot, not a real-time feed or a quantitative risk score.

Each workstream distinguishes documentary evidence, ZRC judgement and an action to prepare. Primary institutional resources are public and labelled as such. Sources checked: Access2Markets (European Commission), ICEX services, Commission public consultations and EU Transparency Register. No open consultation deadline, introduction, institutional partnership or privileged access is asserted without verification.

Members can select workstreams across desks, write their own question and download a text brief preserving sources and evidence/judgement separation. The draft lives only in component state; the interface says to download before changing section or leaving. Nothing is sent to ZRC by the brief tool. Opportunity teaser requests retain the existing authenticated workflow. Additional institutional or representation engagements require confirmation of fit, availability and separate scope.

Full board data remains in the signed-session editorial payload; the public page exposes only its value proposition. ES/EN included. Existing approval, pricing and session checks are preserved.

Validation: Node tests cover bilingual rendering, source-carrying selective export, private/public bundle separation and prior membership/request protections; Vite build and Worker dry run. Browser review uses an isolated fixture of the exact member components, not a production authentication bypass.
